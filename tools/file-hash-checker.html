About

The XAVERT File Hash Checker calculates SHA-256, SHA-384, SHA-512 and legacy SHA-1 checksums locally in your browser for file integrity verification.

Main Features

  • Generate SHA-256, SHA-384 and SHA-512 checksums, plus SHA-1 for legacy verification.
  • Choose files with the file picker or drag and drop.
  • Compare generated hashes with expected checksums.
  • Copy lowercase or uppercase hash values.
  • Download a plain-text verification report.
  • Process files locally with the browser Web Crypto API.

Privacy First

Everything is processed locally within your browser. Your files and generated checksums are never uploaded, transmitted, shared or stored on any server.
