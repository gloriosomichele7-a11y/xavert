About

The XAVERT Password Toolkit combines local password generation, password strength estimation, passphrase generation and SHA hashing.

Main Features

  • Generate multiple secure random passwords with configurable character sets.
  • Generate pronounceable password variants.
  • Estimate password strength and entropy locally.
  • Create cryptographically random passphrases from a large built-in word pool.
  • Generate SHA-256 and SHA-512 hashes.
  • Copy or download generated passwords and hashes.

Privacy First

Passwords, passphrases and hashes are processed locally within your browser and are never uploaded, transmitted, shared or stored on any server.
