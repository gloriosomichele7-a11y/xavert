About

The XAVERT JSON Toolkit provides browser-based formatting, validation, minification, escaping and structural comparison.

Main Features

  • Format and minify valid JSON.
  • Validate syntax and report parsing errors.
  • Load local JSON files without uploading them.
  • Escape and unescape JSON string fragments.
  • Compare nested objects and arrays by path.
  • Copy or download generated results.

Privacy First

Everything is processed locally within your browser. Your JSON data is never uploaded, transmitted, shared or stored on any server.
