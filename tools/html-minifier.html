About

The XAVERT HTML Minifier & Beautifier helps reduce unnecessary whitespace or reformat HTML for easier reading directly in your browser.

Main Features

  • Minify HTML conservatively without flattening raw-text content.
  • Beautify HTML with structured indentation.
  • Preserve comments, script, style, pre and textarea content.
  • Track characters saved and compression percentage.
  • Copy or download processed HTML.
  • Process everything locally in the browser.

Privacy First

Everything is processed locally within your browser. Your HTML code and generated output are never uploaded, transmitted, shared or stored on any server.
