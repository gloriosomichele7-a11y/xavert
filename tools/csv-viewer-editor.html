About

The XAVERT CSV Viewer & Editor lets you inspect and modify CSV files without uploading spreadsheet data to a server.

Main Features

  • Import CSV files up to 10 MB.
  • Automatically detect comma, semicolon, tab and pipe delimiters.
  • Search rows instantly across all editable cells.
  • Sort columns using numeric or text-aware ordering.
  • Create a new CSV from scratch, then edit cells, add rows and delete rows directly in the table.
  • Copy or download the updated CSV data.
  • Preserve the detected delimiter when exporting the file.

Privacy First

Everything is processed locally within your browser. Your CSV files and edited data are never uploaded, transmitted, shared or stored on any server.
