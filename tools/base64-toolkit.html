About

The XAVERT Base64 Toolkit converts readable UTF-8 text into Base64 and decodes valid Base64 data back into readable text directly in your browser.

Main Features

  • Encode UTF-8 and Unicode text into standard Base64 or Base64URL.
  • Decode standard and URL-safe Base64 data.
  • Validate Base64 input before decoding.
  • Detect whether the current input is plain text or valid Base64.
  • Display character counts, UTF-8 byte counts and conversion statistics.
  • Copy encoded or decoded results directly to the clipboard.
  • Download the generated result as a text file.

UTF-8 Support

Modern browser encoding APIs correctly process accented characters, international alphabets, symbols and emoji.

Keyboard Shortcut

Press Enter while working in the input field to run the primary Base64 Encode action. Use Ctrl + Shift + Enter to insert a new line.

Privacy First

Everything is processed locally within your browser. Your input and results are never uploaded, transmitted, shared or stored on any server.
