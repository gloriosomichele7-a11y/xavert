About

The XAVERT CSS Minifier & Beautifier helps developers compress, format and inspect stylesheets without uploading code to a server.

Main Features

  • Minify CSS while preserving strings, URLs and optional license comments.
  • Beautify compact or unformatted CSS with configurable indentation.
  • Check brackets, comments and quoted strings for basic structural errors.
  • Import local CSS files and export the processed result as a .css file.
  • View character, line, rule and compression statistics.
  • Copy results directly to the clipboard.

Important Note

This tool performs safe structural processing and basic validation. It does not replace a full standards-aware CSS parser or build pipeline.

Keyboard Shortcut

Press Ctrl + Shift + B (or Command + Shift + B on macOS) to beautify CSS.

Privacy First

Everything is processed locally within your browser. Your CSS is never uploaded, transmitted, shared or stored on any server.
