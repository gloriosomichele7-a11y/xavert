About


        

          The XAVERT HTTP Header Analyzer inspects pasted request or response
          headers locally in your browser.
        


        
Main Features


        
    
          
  • Parse HTTP request and response header blocks.
    • 
          
  • Check common browser security headers.
    • 
          
  • Inspect caching directives and cache-related headers.
    • 
          
  • Detect server and content information.
    • 
          
  • Preserve duplicate header values where relevant.
    • 
          
  • 
            Identify whether the block is a request, response or header-only
            block.
          
    • 
          
  • Copy or download a plain-text analysis report.
    • 
        


        
Security Scoring


        

          The score is a heuristic based on the presence of common hardening
          headers. A high score does not guarantee that a website is secure, and
          some headers are context-dependent.
        


        
Privacy First


        

          Everything is processed locally within your browser. Your pasted
          headers and generated report are never uploaded, transmitted, shared
          or stored on any server.
