About

The XAVERT Markup Generator creates Schema.org structured data in JSON-LD format for common website entities and content types.

Main Features

  • Generate Article, Product, LocalBusiness, Organization, WebSite, BreadcrumbList, FAQPage, Event, SoftwareApplication, VideoObject and Recipe markup.
  • Use guided fields for nested authors, publishers, offers, ratings, addresses, locations and media.
  • Create repeatable FAQ questions and breadcrumb items.
  • Create Recipe ingredient and instruction arrays.
  • Add advanced custom Schema.org properties with typed values.
  • Check locally defined required and recommended implementation properties before deployment.
  • Edit the generated JSON-LD directly and validate JSON syntax.
  • Copy raw JSON-LD or a safe HTML script tag.
  • Download structured data as a .jsonld file.
  • Combine multiple entities with the built-in @graph builder.
  • Open the official Google Rich Results Test or Schema.org validator for external validation.

Privacy First

Form values, generated JSON-LD, validation results and graph entities are processed locally in your browser. This tool does not require a third-party runtime and does not upload your structured data to XAVERT.

Local checks in this tool are implementation guidance, not a guarantee of Google rich-result eligibility. Search engines can change supported features and requirements over time, and valid structured data must accurately describe content that is visible on the page.
