About

The XAVERT SQL Minifier compresses SQL queries locally in your browser.

Main Features

  • Remove ordinary line and block comments safely.
  • Preserve optimizer hints and executable semantic comments.
  • Protect quoted strings, identifiers and PostgreSQL dollar quotes.
  • Handle MySQL comments, T-SQL temporary tables and Oracle q-quotes.
  • Choose Safe or Maximum Compression.
  • Track characters saved, compression and removed comments.
  • Copy or download the minified SQL file.

Privacy First

SQL processing happens locally within your browser. Your queries are never uploaded, transmitted, shared or stored on any server.
