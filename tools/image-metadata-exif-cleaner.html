About

The XAVERT Image Metadata & EXIF Cleaner reveals metadata stored inside image files and helps you remove common privacy-sensitive metadata before sharing supported images.

Main Features

  • Inspect EXIF, GPS, camera, lens, date, software, XMP, IPTC and other metadata when available in the source format.
  • Detect location, creator information, device identifiers and other privacy-sensitive tags.
  • Search and filter the complete metadata table.
  • Copy GPS coordinates when location metadata is present.
  • Copy or download structured metadata as JSON.
  • Remove common metadata from JPEG, PNG and WebP files without recompressing image pixels when safe.
  • Preserve visual orientation by rendering a clean copy when EXIF orientation cannot safely be removed losslessly.
  • Verify the cleaned file by parsing its metadata again.

Privacy First

Your image is inspected and cleaned locally in your browser and is not uploaded to XAVERT. The ExifReader library is loaded from a third-party CDN when this page opens. Cleaning is available for JPEG, PNG and WebP; other supported formats are inspection-only because safe browser-side metadata rewriting is format-dependent.
