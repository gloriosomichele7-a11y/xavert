About


        

          The XAVERT HTML Entity Encoder / Decoder converts reserved and special
          characters to HTML entities and decodes named or numeric entities back
          into Unicode text.
        


        
Main Features


        
    
          
  • Encode reserved HTML characters safely.
    • 
          
  • Choose named, decimal or hexadecimal entity encoding.
    • 
          
  • Decode named, decimal and hexadecimal numeric entities.
    • 
          
  • Count output characters, entities, lines and UTF-8 bytes.
    • 
          
  • Copy or download the generated result.
    • 
          
  • Process all text locally in the browser.
