About

The XAVERT Spreadsheet Toolkit provides a focused browser workspace for inspecting and cleaning common spreadsheet formats.

Main Features

  • Open XLSX, XLS, ODS and CSV files and switch between worksheets.
  • Edit visible cells, search rows and sort by any column.
  • Trim values and remove duplicate or empty rows.
  • Merge workbook sheets into one data table with source-sheet labels.
  • Export the active data as XLSX, CSV or JSON.

Privacy First

Spreadsheet processing happens locally within your browser. Your files are never uploaded, transmitted, shared or stored on XAVERT servers.
