About

The XAVERT Sitemap Generator creates XML sitemaps directly in your browser.

Main Features

  • Generate a sitemap from one absolute URL per line.
  • Remove duplicate URLs automatically.
  • Apply change frequency and priority values.
  • Use priority 1.0 automatically for site homepages.
  • Copy or download the generated sitemap.xml file.

Privacy First

Sitemap generation happens locally within your browser. Your URLs are never uploaded, transmitted, shared or stored on any server.
