About


        

          The XAVERT User-Agent Parser analyzes common User-Agent strings
          directly in your browser.
        


        
Main Features


        
    
          
  • Detect modern and legacy browsers, webviews and HTTP clients.
    • 
          
  • Identify operating systems, device types and common device models.
    • 
          
  • Detect common search, social, SEO and AI crawlers.
    • 
          
  • Identify rendering engine and architecture where reliably exposed.
    • 
          
  • Recognize Chromium User-Agent Reduction and frozen platform fields.
    • 
          
  • 
            Use User-Agent Client Hints for additional local details when you
            explicitly analyze your current browser and the API is supported.
          
    • 
          
  • Copy or download the generated analysis report.
    • 
        


        
Important Limitation


        

          User-Agent strings can be reduced, frozen or spoofed. The parser reports
          the information that is actually exposed and avoids inferring hidden
          details when the string does not support a reliable conclusion.
        


        
Privacy First


        

          User-Agent parsing and optional Client Hints analysis happen locally
          within your browser. Your input and detected browser details are never
          uploaded, transmitted, shared or stored on any server.
