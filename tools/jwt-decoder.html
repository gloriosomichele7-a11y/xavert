About

The XAVERT JWT Decoder decodes standard three-part JSON Web Tokens directly in your browser.

Main Features

  • Decode Base64URL JWT header and payload segments.
  • Handle UTF-8 and Unicode JSON content correctly.
  • Inspect algorithm, expiration and issued-at claims.
  • Detect expired and not-yet-valid tokens from timing claims.
  • Copy token, header, payload or the complete decoded result.
  • Download decoded JWT data as JSON.

Signature Verification

This tool decodes JWT data only. It does not verify the cryptographic signature and therefore cannot establish that a token is authentic.

Privacy First

Everything is processed locally within your browser. Your JWT tokens and decoded data are never uploaded, transmitted, shared or stored on any server.
