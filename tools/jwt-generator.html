About


        

          The XAVERT JWT Generator creates HS256 JSON Web Tokens directly in
          your browser using the Web Crypto API.
        


        
Main Features


        
    
          
  • 
            Generate HS256 JWT tokens from custom JSON header and payload data.
          
    • 
          
  • Sign tokens using HMAC SHA-256 through Web Crypto.
    • 
          
  • Handle UTF-8 and Unicode JSON content correctly.
    • 
          
  • Format and validate header and payload JSON before signing.
    • 
          
  • Copy the complete token or individual token segments.
    • 
          
  • Download the generated JWT as a text file.
    • 
        


        
Algorithm


        

          This generator supports HS256 only. The JWT header must therefore use
          "alg": "HS256"; other algorithm declarations are
          rejected.
        


        
Privacy First


        

          Header, payload, secret key and generated token remain inside your
          browser and are never uploaded, transmitted, shared or stored on any
          server.
