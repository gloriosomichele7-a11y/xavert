About

The XAVERT HTACCESS Generator creates common Apache configuration snippets for redirects and basic HTTP security headers.

Main Features

  • Generate Force HTTPS rewrite rules.
  • Redirect non-WWW traffic to WWW.
  • Redirect WWW traffic to non-WWW.
  • Create a basic 301 redirect to a target domain.
  • Generate common HTTP security header directives.
  • Copy or download the generated .htaccess file.

Server Compatibility

Generated rewrite rules are intended for Apache installations where mod_rewrite is available. Security header directives require mod_headers.

Privacy First

Everything is generated locally within your browser. Your domain and generated rules are never uploaded, transmitted, shared or stored on any server.
