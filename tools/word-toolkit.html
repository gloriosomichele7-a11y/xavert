About

The XAVERT Word Toolkit helps you inspect and reuse content from modern Microsoft Word DOCX files directly in your browser.

Main Features

  • Preview DOCX content as browser-friendly HTML.
  • Extract clean plain text from Word documents.
  • Convert DOCX content to HTML or Markdown.
  • Inspect word, character, paragraph, table, image and link counts.
  • Inspect extended document metadata and DOCX structure details.
  • Review external hyperlinks and embedded media files.
  • Download embedded document images as a ZIP archive.
  • Create a metadata-cleaned DOCX copy without modifying the original.

Privacy First

Your DOCX file is processed locally in your browser and is not uploaded to XAVERT. The Mammoth conversion library is loaded from a third-party CDN when this page is opened.
