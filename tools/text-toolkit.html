About

The XAVERT Text Toolkit combines common text analysis and transformation tools in one browser-based workspace.

Main Features

  • Count words, characters, sentences, paragraphs and lines.
  • Convert text case and clean extra whitespace.
  • Remove duplicate lines and sort text lines.
  • Find and replace literal text.
  • Create URL-friendly slugs.
  • Encode or decode URL components and Base64 text.

Privacy First

Text processing happens locally within your browser. Your content is never uploaded, transmitted, shared or stored on any server.
