About

The XAVERT Favicon Generator creates a complete favicon, Apple Touch Icon and PWA icon package from one source image.

Main Features

  • Load PNG, JPG, WebP or SVG artwork.
  • Generate a multi-image favicon.ico containing 16×16, 32×32 and 48×48 icon bitmaps.
  • Generate individual 16×16, 32×32 and 48×48 PNG favicons.
  • Generate Apple Touch Icons at 152×152, 167×167 and 180×180, including the conventional apple-touch-icon.png file.
  • Generate 192×192 and 512×512 PWA icons.
  • Optionally generate dedicated maskable PWA icons with the artwork kept inside the standardized central safe zone.
  • Choose contain or cover rendering and add artwork padding.
  • Use transparent, white or custom standard-icon backgrounds.
  • Configure app name, short name, start URL and display mode.
  • Generate site.webmanifest and ready-to-paste HTML head tags.
  • Preview and download individual generated icons.
  • Download the complete package as a ZIP archive.

Privacy First

Your source artwork and generated favicon files are processed locally in your browser and are not uploaded to XAVERT. The ZIP archive is assembled locally with the JSZip library bundled in XAVERT.

SVG uploads are parsed and hardened before rasterization. Scripts, event-handler attributes, embedded active content and external resource references are removed before the SVG is rendered.
