How to add it
  • iPhone or iPad: In Safari, tap Share, then “Add to Home Screen”. In Chrome, tap Share beside the address bar, then “Add to Home Screen”.
  • Android: Open the browser menu and choose “Install app” or “Add to Home screen”.
  • Computer: In Chrome or Edge, use the install icon in the address bar or the browser menu.

An internet connection is still required to use the tools.
